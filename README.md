# vinosconmarypepa.cl

Sitio web de **Vinos con Marypepa**, el podcast de María Paz Jiménez.
Desarrollado por EVO Communication Lab.

## Stack

Astro 4 estático. CSS plano con custom properties. Deploy en Netlify desde `main`.

## Desarrollo

```bash
npm install
npm run dev      # http://localhost:4321
npm run build    # genera dist/
npm run preview  # sirve dist/ localmente
```

## Documentación

- `SPEC.md`: estado técnico, infraestructura y decisiones
- `AGENTS.md`: reglas de trabajo para agentes de código
- `/brief.html`: estado del proyecto para la clienta
